# oddz.click 프로젝트 상세 페이지 연결

완성한 프로젝트 3개에 **자세히 보기** 링크를 추가했습니다.

- 수강신청 연습사이트: 설명 페이지 → 사용자가 제공한 Vercel 주소로 이동
- 나의 일기장: 설명 페이지 준비 완료. 설치 파일은 아직 제공되지 않아 다운로드는 표시하지 않습니다.
- 자료 정리 매크로: 설명 페이지 → 동봉한 v17 Python 소스 ZIP 다운로드. Windows, 한글, Python 3.11 이상이 필요합니다.

## GitHub Pages에 올리기

압축을 해제하고 **폴더 안의** `index.html` 파일과 `themes`, `assets`, `projects`, `downloads` 폴더를 oddz.click 저장소 최상위에 모두 업로드한 뒤 커밋하세요. 기존 `index.html`과 폴더 파일들은 교체하고 `CNAME`은 그대로 둡니다.

일기장 설치 파일을 받으면 `downloads`에 추가하고 `projects/diary.html`의 준비 중 안내를 다운로드 링크로 교체할 수 있습니다. 파일명과 Windows 지원 방식이 확인되기 전까지는 잘못된 링크를 만들지 않았습니다.

처음 3개 프로젝트는 목록 항목 전체를 눌러 상세 페이지로 이동할 수 있습니다. 현재 웹사이트에서 상세 페이지가 404라면 `projects` 폴더가 아직 배포되지 않은 상태입니다.
