# oddz.click 테마 선택 버전

`index.html`은 반짝이 디자인입니다. 상단 **테마** 버튼에서 반짝이, 기계, 게임 · 물빛, 게임 · 노을, 비눗방울을 선택할 수 있습니다. 선택한 테마는 같은 브라우저에서 다음에 `oddz.click`을 열 때에도 적용됩니다.

## GitHub Pages에 올리기

1. ZIP 압축을 해제합니다.
2. **압축 해제한 폴더 안의** `index.html`, `themes` 폴더, `assets` 폴더를 현재 oddz.click GitHub 저장소의 **최상위**에 업로드합니다. 기존 `index.html`은 교체하고 `CNAME` 파일은 그대로 둡니다.
3. 배포가 완료되면 사이트에서 테마 버튼을 눌러 다섯 디자인을 확인합니다.

`index.html`만 따로 업로드하면 다른 테마가 열리지 않습니다. 모든 페이지와 `assets` 폴더를 함께 올려야 합니다. 인터넷 연결이 없으면 외부 웹폰트가 대체 글꼴로 표시될 수 있습니다.
