# oddz.click 프로젝트 목차 및 테마 선택

상단 **테마** 메뉴에서 5가지 디자인을 고를 수 있습니다. 프로젝트 목차는 완성 → 진행 중 → 진행 중인 작업이 끝나면 → 언젠가 할 것 순서이며, 11개 항목이 모든 테마에 동일하게 표시됩니다.

## GitHub Pages에 반영하기

1. ZIP 파일의 압축을 풉니다.
2. 압축을 푼 **폴더 안의** `index.html`, `themes` 폴더, `assets` 폴더를 현재 oddz.click GitHub 저장소의 최상위에 업로드하고 커밋합니다. 기존 파일은 교체하고 `CNAME`은 그대로 둡니다.
3. 배포된 사이트에서 테마를 바꿔도 동일한 목차가 나오는지 확인합니다.

ZIP 파일만 저장소에 올리거나 `index.html`만 교체하면 다른 테마의 목차는 갱신되지 않습니다.
