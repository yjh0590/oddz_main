나의 일기장

기존 일기 앱의 제한을 벗어나 내가 쓰고 싶은 방식대로 만든 개인용 Windows 일기장.

기록 시기 · 2026.05.04

왜 만들었나

기존에 사용하던 일기 앱의 유료화와 기능 제한이 아쉬워서 내가 실제로 쓰는 기능만 담은 일기장을 만들기로 했다. 날짜별 기록을 쓰고, 폰트 종류와 크기, 글자 색을 조절할 수 있도록 구성했다.

넣고 싶었던 기능

비밀번호 잠금, 사진과 동영상 첨부, 위치 기록, PDF 내보내기를 기획했다. 기록을 내 PC에서 열어 보고 오래 보관할 수 있다는 점도 중요했다. 테마와 폰트를 더 자유롭게 고르는 기능은 이후에도 계속 다듬을 대상으로 남겨 두었다.

만들고 배포하면서

AI 개발 도구의 도움으로 화면과 기능을 빠르게 만들 수 있었지만, 코드가 커질수록 변경 사항을 따라가고 개발 도구의 사용량을 관리하는 일이 필요하다는 걸 배웠다.

처음 글을 쓸 때는 배포를 계획하고 있었다. 이후 Windows 설치 파일을 만들고, 다른 Windows 환경에서 설치했을 때 기존 개인 일기와 비밀번호가 나타나지 않는지 확인했다.
