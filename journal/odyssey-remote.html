오디세이 리모컨 만들기

게임하려고 일어나서 모니터 버튼을 더듬는 일을 그만두기로 했다.

2026.11.08

모니터 버튼 대신

모니터 하나에 PC와 닌텐도 스위치를 같이 연결해 두고 쓴다. 화면을 바꿀 때마다 모니터 뒤쪽의 작은 버튼으로 메뉴를 열어야 해서, 아이폰으로 입력 전환과 밝기 조절을 하는 리모컨을 만들었다.

모니터에 직접 말 걸기

모니터는 DDC/CI라는 방식으로 케이블을 통해 밝기나 입력 같은 설정을 받을 수 있다. Windows의 모니터 제어 기능을 부르는 작은 C# 명령줄 프로그램을 만들어, 입력을 DisplayPort(PC)와 HDMI(스위치) 사이에서 바꾸고 밝기를 0~50 사이로 맞추게 했다.

아이폰 리모컨

PC에서 Node.js 서버가 이 프로그램을 대신 실행하고, 같은 Wi-Fi에 있는 아이폰은 웹 페이지 버튼으로 서버에 요청만 보낸다. Safari에서 홈 화면에 추가하면 주소창 없는 앱처럼 열리고, 버튼을 누를 때 짧은 진동도 준다. 밝기는 슬라이더와 ±5 버튼, 야간·표준·최대 세 가지 프리셋으로 맞춘다.

되돌아오는 안전장치

스위치 화면으로 넘긴 뒤 PC 화면으로 돌아오지 못하면 리모컨을 다시 띄울 방법이 없다. 그래서 처음 시험할 때 쓰도록, 스위치 화면으로 넘겼다가 5초 뒤 자동으로 PC 화면으로 돌아오는 테스트 모드를 넣었다.
