강의 영상 대본화 가이드— 강의 영상에서 공부 자료까지

강의 영상을 MP3로 변환하고 대본을 공부 자료로 만들기까지, 반복하던 과정을 한 흐름으로 묶었다.

기록 시기 · 2026.09.25

반복하던 작업에서 시작

강의를 들을 때마다 LMS에서 강의 영상을 내려받고, 영상에서 음성만 추출한 뒤 클로바노트에 올려 대본을 만들었다. 다시 그 대본을 내려받아 ChatGPT에 넣고 공부 자료로 정리했다. 한 번은 괜찮지만 강의가 쌓이면 파일을 옮기고 변환하는 일이 번거로웠다. 그래서 이 과정을 순서대로 안내하고 MP4를 MP3로 바꿔 주는 ‘강의 영상 대본화 가이드’를 만들었다.

처음에는 영상만 넣으면 대본까지 자동으로 나오는 프로그램을 생각했다. 하지만 무료로 사용하는 클로바노트의 업로드와 대본 다운로드까지 프로그램이 대신 처리하는 것은 적절하지 않았다. 유료 음성 인식 API를 붙이면 비용도 발생한다. 결국 영상의 음성을 추출하는 일은 프로그램이 맡고, 클로바노트 로그인·업로드와 대본 다운로드는 사용자가 직접 하도록 나눴다.

강의에서 공부 자료까지 이어지는 화면

강의 영상 내려받기, MP3 변환, 클로바노트 업로드, TXT 대본 다운로드, 공부 프롬프트 선택, ChatGPT 활용 순서로 화면을 구성했다. 처음 쓰는 사람도 다음에 무엇을 해야 하는지 알 수 있도록 단계를 표시했다. 색상은 따뜻한 파란색 계열로 잡고 둥근 글꼴과 버튼 간격을 조정했으며, 처음부터 다시 시작하는 버튼도 넣었다.

Windows 앱에서 웹 버전으로

Windows 앱을 만든 뒤에는 브라우저에서도 사용할 수 있으면 더 편하겠다고 생각해 웹 버전도 제작했다. 웹에서는 브라우저용 FFmpeg 구성 요소를 불러와 선택한 MP4를 MP3로 변환한다. 선택한 영상과 생성된 음성을 외부 서버로 보내지 않도록 구성했다.

웹을 시험할 때 변환 도구를 불러오는 데 시간이 걸렸다. 아주 작은 MP4도 변환되지 않아 처음에는 용량 제한을 의심했지만, 개발자 도구에서 핵심 파일을 불러오는 오류를 발견했다. 구성을 수정한 뒤 작은 MP4의 변환을 확인했다. 큰 강의 영상은 기기 성능과 브라우저 환경에 따라 어디까지 안정적으로 처리되는지 더 시험해야 한다.

웹 배포와 설치 파일 만들기

웹 파일을 GitHub 저장소에 올리고 GitHub Pages로 배포했다. 처음 실행된 배포는 성공했지만, 이후 수동으로 다시 실행한 작업에서는 Pages 서버 오류가 났다. 실패한 단계만 재실행했을 때는 필요한 빌드 결과물을 찾지 못했다. 이 과정을 겪으며 파일을 빌드하는 단계와 사이트를 게시하는 단계가 다르다는 것을 배웠다.

Windows 앱은 개발용 파일을 그대로 전하기보다 설치 파일 하나로 사용하게 만들고 싶었다. Windows용 ffmpeg.exe와 ffprobe.exe를 앱에 포함하고 직접 만든 아이콘을 실행 파일과 창에 적용했다. Inno Setup으로 앱과 필요한 파일을 함께 설치하는 파일도 만들었다.

이후에 확인할 것

웹 버전은 배포했고 Windows 설치 파일도 만들었다. FFmpeg가 따로 설치되지 않은 PC에서 설치 파일만으로 MP3 변환이 되는지 확인하는 일이 남았다. 확인을 마치면 설치 파일을 GitHub Releases에 올리고 개인 사이트에서 웹 사용과 Windows 다운로드를 각각 연결할 계획이다.

처음 목표는 단순히 변환 버튼을 만드는 것이었다. 작업하면서 더 중요하다고 느낀 것은 사용자가 강의 영상에서 공부 자료까지 가는 길을 덜 헤매게 하는 일이었다. 대본 작성은 여전히 클로바노트에서 직접 하지만, 반복하던 변환과 다음 단계 안내를 한 흐름으로 묶었다는 점이 의미 있었다.
