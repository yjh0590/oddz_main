수강신청 연습사이트

처음에는 실행 파일을 생각했다가 웹으로 방향을 바꾼 첫 배포 프로젝트.

기록 시기 · 2025.08–2026.05

2025.08.22 · 처음 만든 연습 사이트

처음에는 실행 파일로 배포할 생각이었지만, 자바스크립트로 만든 화면을 웹사이트로 공개하는 편이 접근하기 쉽겠다고 생각해 방향을 바꿨다. 수강신청에 앞서 숫자를 빠르게 입력해 보는 연습 모드와 무한 모드, 랭킹과 개인 기록 화면을 구상했다.

Supabase와 GitHub를 처음 써 보면서 데이터 저장과 배포 과정을 하나씩 익혔다. 모바일에서 숫자를 입력할 때 나오는 키보드, 기록을 다시 찾는 동선, 첫 화면에 필요한 정보를 계속 고쳤다.

2025.09.04 · 사용자 피드백과 수정 목록

숫자를 다 입력한 뒤에만 결과가 보이기보다 입력하는 중에도 바로 반응하면 실전처럼 더 촉박하게 느껴질 것 같다는 의견이 있었다. 과를 선택하지 않아도 결과를 먼저 볼 수 있게 하고, 방금 낸 기록도 학과 선택 화면에서 곧바로 확인할 수 있게 하고 싶었다.

색 조합과 배경, 폰트를 손보고, 랭킹에는 명예의 전당을 더하는 방안을 생각했다. 방문자 수와 이미지 표시 오류도 확인했다. 사용자는 있었지만 피드백이 생각만큼 모이지 않아, 실제 서비스를 운영하면 의견을 받는 일 자체도 중요하다는 걸 느꼈다.

2026.05.04 · 첫 완성 프로젝트를 돌아보며

기획부터 배포까지 처음으로 전 과정을 마친 포트폴리오 작업이다. 당시 기록에는 실사용자와 접속자가 1만 명에 도달했다고 적어 두었다.

초기 버전인 만큼 기능 보완과 정리할 부분이 남아 있지만, 지금은 계속 기능을 늘리기보다 첫 배포를 완주했다는 기록으로 공개하고 있다.
