GitHub Pages와 DNS

GitHub Pages로 HTML·CSS·JavaScript 파일을 공개하고, DNS의 A 레코드와 CNAME으로 oddz.click을 연결했다. 배포 주소가 열리는지, 구매한 도메인으로 접속할 수 있는지, HTTPS가 적용됐는지 따로 확인했다.

iframe과 동영상 이벤트

가톨릭대 LMS는 강의 화면 안의 iframe에서 영상을 재생한다. UniPlayer의 이벤트와 Chrome의 사용자 입력 처리를 함께 살피면서 강의 페이지 이동과 실제 재생 시작을 구분했다.
