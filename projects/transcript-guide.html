강의 영상 대본화 가이드

강의 영상에서 공부에 활용할 대본을 만드는 과정을 단계별로 안내하는 웹 도구입니다.

어떤 프로젝트인가요?

강의 영상을 준비하고 음성을 MP3로 변환한 다음, 클로바노트에서 대본을 만들고 내려받은 텍스트를 학습에 활용하는 흐름을 정리했습니다.

  • 강의 영상에서 MP3 음성을 준비합니다.
  • 클로바노트에 업로드해 대본을 만듭니다.
  • 내려받은 텍스트를 학습 자료로 활용합니다.

웹에서 사용하기

웹 가이드 열기 ↗

설치 없이 브라우저에서 이용할 수 있습니다.

Windows 앱 설치하기

컴퓨터에 설치해서 사용하려면 아래 설치 파일을 받으세요.

Windows 설치 파일 다운로드 ↓

Windows용 설치 파일 · v1.0.0 · 약 90MB

시작 전에 준비하세요

공부할 강의 영상 파일(MP4), 클로바노트 계정, ChatGPT 계정을 준비하세요. 영상은 이용 권한이 있는 파일을 사용하세요.

설치 없이 시작하려면

웹 버전으로 시작하세요. 처음 변환할 때 도구를 불러오는 시간이 필요할 수 있습니다.

긴 영상·큰 파일이라면

Windows 앱을 권장합니다. 웹 변환이 오래 걸리거나 실패할 때도 앱으로 시도해 보세요.

이 순서로 진행하면 됩니다

MP4 → MP3 → 클로바노트 → TXT → 프롬프트 → ChatGPT

  1. 강의 영상 준비하기

    공부할 MP4 파일을 컴퓨터에 저장하세요.

  2. 영상에서 음성 추출하기

    웹 가이드 또는 Windows 앱에서 영상을 선택하고 MP3로 변환한 뒤 내려받으세요.

  3. 클로바노트에서 대본 만들기

    클로바노트에 MP3 파일을 직접 업로드하고 음성 인식이 끝날 때까지 기다리세요.

  4. 대본을 TXT로 내려받기

    완성된 노트의 텍스트를 TXT 파일로 저장하세요.

  5. 공부할 프롬프트 선택하기

    가이드에서 원하는 학습용 프롬프트를 선택하고 복사하세요.

  6. ChatGPT에서 공부하기

    TXT 파일과 복사한 프롬프트를 함께 전달하세요. 대본의 인식 오류와 답변의 정확성은 강의 자료로 확인하세요.

음성 인식은 클로바노트에서 진행합니다. 업로드와 대본 다운로드는 직접 해야 합니다.

진행이 막혔나요?

웹 변환 도구가 오래 로딩돼요

처음에는 도구 다운로드로 시간이 걸릴 수 있습니다. 인터넷 연결을 확인하고, 계속 진행되지 않으면 Windows 앱을 이용해 보세요.

큰 영상이 변환되지 않아요

웹에서는 파일 크기와 브라우저 메모리의 영향을 받습니다. 더 작은 파일로 시도하거나 Windows 앱에서 변환해 보세요.

내려받은 MP3 파일이 안 보여요

브라우저의 다운로드 목록과 컴퓨터의 다운로드 폴더를 확인하세요. 저장 위치를 직접 선택했다면 해당 폴더를 확인하세요.

프롬프트 복사가 안 돼요

웹 주소가 https://study.oddz.click/인지 확인하세요. 계속 복사되지 않으면 프롬프트 내용을 직접 선택해 복사하세요.
