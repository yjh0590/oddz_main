선택한 강의를 순서대로 재생하고, 영상이 끝나면 다음 강의로 자동 이동하는 Chrome 확장프로그램입니다.

가톨릭대 LMS 확장프로그램 다운로드

확장프로그램 다운로드 · v0.6.9 ↓

PC Chrome용 · 직접 설치 필요 · 가톨릭대 LMS 전용

설치 방법: ZIP 압축 해제 → chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램을 로드합니다

압축을 푼 폴더에서 manifest.json이 보이는 폴더를 선택하세요. 자세한 설치·사용 순서는 위의 사용법 탭에서 확인할 수 있습니다.

지원하는 기능

  • 여러 과목·강의 선택 가능
  • 강의 종료 후 다음 강의 자동 이동
  • 다음 강의 자동 재생
  • 전체 시작 / 중지 지원
  • Chrome 확장프로그램 형태로 설치

자동재생을 위해 Chrome의 디버깅 기능을 사용하므로 실행 중 브라우저 상단에 디버깅 안내가 표시될 수 있습니다.

처음 설치하기

  1. ZIP 다운로드·압축 해제

    다운로드한 ZIP을 계속 사용할 위치에 압축 해제하세요.

  2. 확장프로그램 관리 열기

    Chrome 주소창에 chrome://extensions를 입력하세요.

  3. 개발자 모드 켜기

    오른쪽 위 개발자 모드를 켜고 압축해제된 확장 프로그램을 로드합니다를 누르세요.

  4. 압축을 푼 폴더 선택

    manifest.json이 들어 있는 catholic-lms-autoplay-v0.6.9 폴더를 선택하세요. 이 ZIP에는 별도의 extension 폴더가 없습니다.

  5. LMS 화면 열기

    가톨릭대 LMS에 로그인하고 과목의 강의/출결 페이지를 새로고침하세요.

설치한 폴더는 삭제하거나 옮기지 마세요. 같은 LMS를 제어하는 이전 확장프로그램은 먼저 끄세요.

오늘 들을 강의 선택하기

과목 선택 → 영상 선택 → 오늘 재생할 목록 → 전체 시작

  1. 과목 선택

    강의/출결 페이지에 표시되는 오늘의 강의 화면에서 듣고 싶은 과목을 선택하세요.

  2. 영상 선택·목록 추가

    오늘 들을 강의를 골라 오늘 재생할 목록에 추가하세요. 여러 과목의 강의를 한 목록에 섞어 담을 수 있습니다.

  3. 전체 시작

    재생할 목록과 순서를 확인하고 전체 시작을 누르세요. 영상이 끝나면 다음 선택 강의로 이동해 재생합니다.

  4. 중지

    자동 실행을 멈추려면 중지를 누르세요.

화면을 접으면 오른쪽의 작은 ▶ 버튼으로 다시 열 수 있습니다. 페이지를 새로고침하면 펼친 화면으로 시작합니다.

설치·실행이 잘 안 될 때

매니페스트를 로드할 수 없다고 나와요

먼저 ZIP을 압축 해제하세요. 선택한 폴더를 열었을 때 manifest.json이 바로 보여야 합니다.

강의 목록이나 화면이 나타나지 않아요

가톨릭대 LMS의 강의/출결 페이지인지 확인하세요. 실행 중이 아니라면 LMS 페이지를 새로고침하고, 목록 새로고침 버튼으로 다시 읽어 보세요.

브라우저 상단에 디버깅 안내가 떠요

다음 강의를 자동 재생하기 위해 사용하는 Chrome 기능의 안내입니다. 디버깅 연결을 강제로 종료하면 다음 영상 자동재생이 작동하지 않을 수 있습니다.

업데이트하기

재생을 중지하고 새 ZIP을 압축 해제한 뒤, 기존 설치 폴더에 새 파일을 덮어쓰세요. chrome://extensions에서 확장프로그램을 새로고침하고 LMS 탭도 새로고침하세요.

사용 중 확인할 점

자동 실행 중에는 LMS 탭을 열어 두고 강의/출결 화면을 직접 새로고침하지 마세요. LMS나 플레이어 구조가 바뀌면 동작 확인이 필요합니다.

영상 재생 완료와 LMS의 출석·진도 인정은 구분해서 확인하세요. 전체 사용방법은 다운로드 ZIP의 README.md에도 들어 있습니다.
