v0.7.18의 파일·폴더 정리 기능에 성능 개선과 배포 구조 정리를 반영했습니다.

  • 파일 선택을 더 가볍게: 체크할 때 목록 전체를 다시 만들던 처리를 줄였습니다. 용량 새로고침과 남길 파일 변경도 필요한 정보만 갱신합니다.
  • 폴더 비교의 불필요한 읽기 감소: 경로와 크기로 먼저 구분한 뒤 필요한 파일만 내용을 비교합니다. 삭제 직전 변경 여부와 내용 재검증은 유지합니다.
  • 정리 후 기다림 감소: 폴더 삭제 후 전체 중복·ZIP 검사를 반복하지 않고 검사 결과와 용량 목록을 갱신합니다.
  • 진행 상태 안내: 폴더 내용 비교 중 확인하고 있는 파일을 표시하고, 다른 작업이 겹쳐 실행되지 않도록 했습니다.
  • 설치 없이 실행: 공식 서명을 확인한 Python 3.13.17 런타임을 ZIP에 포함했습니다.

포함 소스: main · 1d5c73a. 자동 테스트 58개 중 57개 통과, 심볼릭 링크 생성 권한이 필요한 1개는 건너뛰었습니다. 실제 Windows 화면·휴지통·Chrome 도우미의 전체 사용 흐름은 추가 확인이 필요합니다.

이렇게 실행하세요

  1. ZIP 파일을 내려받아 새 폴더에 전체 압축을 풉니다. ZIP 안에서 바로 실행하지 마세요.
  2. 쓱-싹.exe를 더블클릭합니다.
  3. 처음이라면 ‘파일 구조화 → 가상 테스트 실행’으로 연습하거나 작은 테스트 폴더를 선택합니다.
  4. 검사 결과와 남길 기준을 확인한 뒤 정리할 항목만 선택해 Windows 휴지통으로 옮깁니다.

압축을 풀면 실행 파일과 app 폴더가 있습니다. 다른 위치로 옮길 때는 둘을 함께 옮겨 주세요. 바탕화면에서는 EXE의 Windows 바로가기를 만들어 실행할 수 있습니다.

어떤 일을 할 수 있나요?

  • 파일 정리: 복사본, 같은 이름, 압축 해제한 ZIP, 작업 버전, 변환 파일 등의 후보를 살펴봅니다. 같은 이름 분류에서는 버전·날짜·복사본 번호·직접 지정 기준으로 남길 파일을 고를 수 있습니다.
  • 폴더 정리: 선택한 위치 바로 아래의 비슷한 버전 이름 폴더를 찾고, 두 폴더의 경로·크기·내용을 비교합니다. 차이를 확인한 뒤 후보 폴더 전체를 휴지통으로 옮깁니다.
  • 정크 파일: 오래된 임시 파일과 알려진 캐시 후보를 확인합니다.
  • 폴더 용량: 폴더별 용량과 하위 폴더를 살펴봅니다.
  • 이전 버전 보관함 복원: 옛 버전이 앱 보관함에 옮긴 파일만 원래 위치로 복원합니다. 현재 정리는 Windows 휴지통을 사용하며 새 보관함 이동은 지원하지 않습니다.
  • Chrome 다운로드: 도우미 등록 후 다운로드 기록에 연결된 실제 파일을 비교해 선택한 파일을 휴지통으로 옮깁니다. 성공한 파일의 기록만 정리하며, 이미 없는 파일의 기록은 그대로 둡니다.
  • 파일 구조화: 폴더 만들기·이름 변경·이동, TXT/MD/CSV 텍스트 수정본 저장, 99_아카이브, 즐겨찾기를 제공합니다.

정리 후보가 모두 불필요한 파일이라는 뜻은 아닙니다. 파일명과 위치를 확인하고 필요한 항목은 남겨 주세요.

Chrome 다운로드 연결은 처음 한 번만

  1. 앱의 ‘크롬 다운로드 → 크롬 연결 도우미 등록하기’를 누릅니다.
  2. Chrome 확장 프로그램 화면의 ‘개발자 모드’를 켜고 ‘압축해제된 확장 프로그램을 로드합니다’를 선택합니다.
  3. 배포 폴더 안의 크롬 다운로드 연결 도우미 폴더 자체를 선택합니다.
  4. 앱으로 돌아와 ‘다운로드 파일 확인’을 누릅니다. 기존 도우미가 있다면 예전 확장을 제거하고 새 폴더를 등록하세요.

일반 파일·폴더 정리만 쓸 때는 확장을 등록하지 않아도 됩니다. 사용할 Chrome 프로필마다 등록하고 도우미 폴더는 같은 위치에 보관하세요.

정리한 파일과 공간은 어떻게 되나요?

휴지통으로 옮긴 파일은 Windows 휴지통에서 복원합니다. 비우기 전에는 실제 빈 공간이 바로 늘지 않을 수 있습니다. ‘휴지통 비우기’는 현재 사용자의 모든 드라이브 휴지통에 있는 기존 파일까지 영구 삭제하므로 표시된 범위를 확인하세요.
