쓱-싹

쌓여 가는 다운로드 폴더, 정리할 파일부터 골라 보세요.
파일 검사부터 보관과 복원까지 한곳에 담은 Windows 파일 정리 도우미입니다.

쓱-싹 다운로드

v0.7.1 · Windows x64 · Chrome 앱 창 버전

Windows ZIP 다운로드 ↓

필요 환경: Windows 64비트, Python 3.9 이상(tkinter 포함). Chrome을 설치하면 주소창 없는 앱 창으로 열립니다. Chrome을 찾지 못하면 기본 창으로 열립니다.

현재 개발 배포본입니다. EXE에 디지털 서명이 없어 Windows에서 ‘알 수 없는 게시자’가 표시될 수 있습니다. 실제 Windows에서의 실행과 화면 배치는 추가 확인이 필요합니다.

이렇게 실행하세요

  1. ZIP 파일을 내려받아 전체 압축을 풉니다.
  2. 쓱-싹.exe를 더블클릭합니다.
  3. ‘폴더 선택하기’로 정리할 폴더를 선택합니다.
  4. 검사 결과를 검토한 뒤 원하는 파일만 선택해 휴지통이나 앱 보관함으로 옮깁니다.

압축을 풀면 실행 파일과 app 폴더가 있습니다. 다른 위치로 옮길 때는 둘을 함께 옮겨 주세요. 바탕화면에서는 EXE의 Windows 바로가기를 만들어 실행할 수 있습니다.

어떤 일을 할 수 있나요?

  • 파일 정리: 복사본, 같은 이름, 압축 해제한 ZIP, 작업 버전, 변환 파일 등의 정리 후보를 살펴봅니다.
  • 정크 파일: 오래된 임시 파일과 알려진 캐시 후보를 확인합니다.
  • 폴더 용량: 폴더별 용량과 하위 폴더를 살펴봅니다.
  • 보관·복원: 앱 보관함으로 옮긴 파일을 원래 위치로 복원합니다. 휴지통에 보낸 파일은 Windows 휴지통에서 복원합니다.
  • Chrome 다운로드 기록: 별도 도우미 등록 후 원래 위치에 없는 파일의 다운로드 완료 기록을 정리합니다. 실제 파일은 그대로 남습니다.

정리 후보가 모두 불필요한 파일이라는 뜻은 아닙니다. 파일명과 위치를 확인하고 필요한 항목은 남겨 주세요.

파일 정리 도구에서 시작해 아이콘, 둥근 카드, 전용 글꼴과 Chrome 앱 창을 적용한 과정을 정리했습니다.
