나의 일기장

오프라인에서도 일기를 쓰고 보관할 수 있도록 만든 데스크톱 앱입니다.

어떤 프로젝트인가요?

날짜별로 일기를 기록하고, 테마와 글꼴을 바꾸거나 기록을 PDF로 내보낼 수 있습니다. Windows PC에 설치해 오프라인에서도 사용할 수 있습니다.

  • 데스크톱에서 사용하는 일기장
  • 달력과 글 편집 기능
  • PDF로 기록 내보내기

사용하기

Windows 설치 파일 다운로드 · v1.0.0

Windows 64비트용 설치 파일입니다. 다운로드한 파일을 실행해 설치하면 바탕화면 아이콘으로 일기장을 열 수 있습니다.

일기와 앱 비밀번호는 각 Windows 사용자 계정의 로컬 데이터 폴더에 저장됩니다. 설치 파일에는 개인 일기가 포함되지 않습니다.
