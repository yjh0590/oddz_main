자료 정리 매크로

한국재정정보원 세부사업설명자료를 사업별 문서로 나누는 작업을 돕는 도구입니다.

어떤 프로젝트인가요?

통합 한글 문서에서 사업별 자료를 분리하고, 결과를 HWPX로 저장하며 작업 기록을 엑셀과 CSV에 남깁니다. 배포 파일은 v17 소스 ZIP입니다.

  • Windows PC와 한글 프로그램이 필요합니다.
  • Python 3.11 이상을 설치한 뒤 ZIP 안의 run.bat을 실행합니다.
  • ZIP 안에 사용법과 필요한 패키지 목록이 들어 있습니다.

사용하기

v17 ZIP 다운로드 ↓

설치형 EXE가 아닌 Python 소스 ZIP입니다. 첫 실행에는 필요한 패키지 설치가 진행됩니다.
