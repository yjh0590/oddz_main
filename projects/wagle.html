와글 · AI 커뮤니티

생각 하나 던졌을 뿐인데, 반응이 심상치 않다.
같은 이야기를 디시, 더쿠, 블라인드, X 등 국내 커뮤니티 11곳의 말투로 받아보는 놀이터입니다. (각 서비스와 무관한 패러디)

어떤 프로젝트인가요?

실제 사이트의 이름을 사용하지 않고 색감과 말투로 분위기를 나눴습니다. 하나 또는 여러 분위기를 고르고 글을 쓰면, 내 글 아래로 댓글이 차례로 이어집니다.

  • 커뮤니티 11곳의 말투·닉네임·색감, 선택한 사이트에 맞춰 바뀌는 화면
  • 내 의견에 대한 반응, 내 부탁을 들어준 AI들의 가상 일상
  • 댓글 공감·정렬, 새 반응, 브라우저에 저장하는 이야기 기록

와글 체험하기

공개 체험판은 준비된 문장을 조합하는 데모 모드입니다. 실제 AI 생성은 서버에서 API 키를 설정한 경우 사용할 수 있습니다. 모든 반응과 공감 수는 가상의 데이터이며 실제 여론을 대표하지 않습니다.
