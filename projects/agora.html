AGORA · 철학자들의 광장

내 생각을 철학자들에게 물어본다면?
질문을 광장에 던지면 고대부터 현대까지 동서양 철학자 6명이 각자의 사상으로 한 줄씩 답합니다.

어떤 프로젝트인가요?

군대에 있을 때 떠올린 생각에서 시작한 개인용 광장입니다. 진지한데 피식 웃기는 톤을 노리되, 답은 실제 사상에 근거합니다.

  • 철학자 40명 중 질문마다 6명을 고름 (동양 2명 이상, 시대 고르게)
  • 답마다 근거가 된 개념을 '사상 꼬리표'로 표시 (예: 칸트 · 정언명령)
  • 실제로 하지 않은 말을 명언처럼 꾸미지 않음

광장 열기

서버 없이 브라우저가 Claude API를 직접 호출합니다. 잠긴 키의 비밀번호나 본인의 Anthropic API 키가 있어야 답을 받을 수 있습니다. 답은 AI가 철학자의 사상을 바탕으로 지어낸 것이며, 실제 인물의 발언이 아닙니다.
