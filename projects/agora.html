AGORA · 철학자들의 광장

아무 질문이나 광장에 던지면,
스물 몇 세기의 철학자들이 한 줄씩 답합니다.

광장에 가기

혼자 쓰는 공간이라 비밀번호(또는 내 Anthropic API 키)가 있어야 질문할 수 있습니다.

광장 열기 ↗

어떤 곳인가요?

군대에 있을 때 떠올린, 내 생각을 철학자들에게 물어보는 광장입니다. "솔방울을 가장 멀리 보내는 방법" 같은 엉뚱한 질문에도 소크라테스는 되묻고, 칸트는 보편화해 보고, 장자는 바람에 맡깁니다.

  • 고대부터 근현대까지 동서양 철학자 40명 중 질문마다 6명 선정
  • 진지한 말투로, 각자의 실제 사상에 근거한 한 줄 답
  • 답마다 근거가 된 개념을 '사상 꼬리표'로 표시
  • 최근 질문 20개를 그 기기에만 기록

현재 버전

서버 없는 정적 페이지가 브라우저에서 Claude API를 직접 호출합니다. API 키는 비밀번호로 암호화해 두고, 비밀번호를 입력하면 브라우저 안에서 풀립니다. 질문과 답은 Anthropic 외에는 어디로도 보내지 않습니다.

답은 AI가 각 철학자의 사상을 바탕으로 지어낸 것이며, 실제로 그들이 한 말이 아닙니다.
